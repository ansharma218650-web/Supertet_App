# SuperTET PRT Practice App

Run:
    pip install -r requirements.txt
    streamlit run app.py

Admin password: edit `.streamlit/secrets.toml` (default: admin123)

Add content:
- Admin page -> add one question / bulk upload CSV or JSON / manage
- or drop JSON files into data/practice/ (one per subject) and
  data/test_series/<series_name>/<test_name>.json
